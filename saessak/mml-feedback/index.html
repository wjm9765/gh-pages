fit과 predict의 역할

fit(X_train, y_train)

정답이 있는 학습 데이터에서 규칙이나 파라미터를 배웁니다.

학습 데이터 + 정답 → 모델

predict(X_test)

배운 모델에 새 입력을 넣어 예측 클래스를 얻습니다.

새 입력 + 모델 → 예측
predict_proba는 모델이 제공할 때 클래스별 확률을 반환합니다. 모든 분류기에 있는 메서드는 아닙니다.

정밀도와 재현율은 질문이 다르다

정밀도 · Precision

TP / (TP + FP)

양성이라고 예측한 것 중 얼마나 맞았나?

예시: 6 / 8 = 0.75

재현율 · Recall

TP / (TP + FN)

실제 양성 중 얼마나 찾아냈나?

예시: 6 / 10 = 0.60

F1은 정밀도와 재현율의 조화평균입니다. 어느 오류를 더 줄여야 하는지는 문제의 비용에 따라 결정합니다.

SOFTMAX · 다중 분류

클래스별 점수를 확률로 바꾼다

z = xW + b

클래스가 3개면 한 샘플에서 점수도 3개가 나옵니다.

z = [2, 1, 0]
pₖ = ezₖ / Σⱼezⱼ

softmax 결과는 모두 0~1 사이이고 합은 1입니다.

p ≈ [0.665, 0.245, 0.090]
가장 큰 점수의 클래스가 가장 큰 확률을 얻습니다. predict는 보통 그 클래스를 반환하고, predict_proba는 확률을 반환합니다.
