CHAPTER 5 · 회귀

오차를 하나의 점수로 만든다

MAE · 평균 절대 오차

MAE = ⅟n ∑ |yᵢ − ŷᵢ|

오차의 크기를 그대로 더합니다.
단위는 목표값 y와 같습니다.

MSE · 평균 제곱 오차

MSE = ⅟n ∑ (yᵢ − ŷᵢ)²

큰 오차에 더 큰 비용을 부과합니다.
예측값에 대해 매끄럽게 미분됩니다.

잔차가 1, 1, 4라면 → MAE = 2 / MSE = 6
MSE가 언제나 더 좋은 것은 아닙니다. 큰 오차의 비용과 이상치의 영향을 고려해 지표를 선택합니다.

평가 지표마다 보는 오차가 다르다

지표계산과 해석주의할 점
MAE ↓평균 절대 오차큰 오차를 MSE만큼 강조하지 않음
RMSE ↓√MSE · 목표값과 같은 단위큰 오차와 이상치에 민감
R² ↑1 − 잔차제곱합 / 전체제곱합1이 최상 · 음수도 가능
RMSLE ↓log(1+y) 공간의 RMSE정답·예측값이 음수가 아니어야 함
R² = 0은 해당 평가 데이터의 평균값만 예측하는 기준과 같은 수준입니다.
모델 비교는 같은 데이터 분할, 같은 지표에서 수행합니다.

다항 회귀는 특성을 확장한 선형 모델이다

ŷ = b + w₁x + w₂x²

입력

x

특성 확장

x, x², x³, …

선형 결합

확장한 특성에 가중치 적용

  • x에 대한 그래프는 곡선이어도, 계수 w에 대해서는 선형입니다.
  • 차수가 높아지면 복잡한 패턴을 표현하지만, 잡음까지 맞출 수 있습니다.
  • PolynomialFeatures로 특성을 만들고 회귀 모델과 연결합니다.
“곡선이면 비선형 회귀다”라고 판단하지 말고, 무엇에 대해 선형인지 확인합니다.

목적함수 = 데이터 오차 + α × 규제항

로지스틱 회귀: 로짓 → 확률 → 클래스

① 로짓 · Logit

입력의 선형 결합으로
분류 점수 계산

z = wᵀx + b

② 시그모이드

로짓을 0~1 사이의
클래스 확률로 변환

p = σ(z)
= 1 / (1 + e−z)

③ 임계값 적용

확률을 기준으로
최종 클래스 결정

p ≥ 0.5 → 1
p < 0.5 → 0
예: z = 1.386 → p ≈ 0.8 → 클래스 1
predict_proba: 클래스 확률   /   predict: 최종 클래스
이진 분류 · 임계값 0.5 예시16
CHAPTER 5 · 회귀

분류의 손실은 정답에 부여한 확률을 본다

BCE = −⅟n ∑ [ yᵢ log pᵢ + (1 − yᵢ) log(1 − pᵢ) ]
실제 정답예측 p = P(y=1)한 샘플의 손실
y = 10.9−log(0.9) ≈ 0.105
y = 10.1−log(0.1) ≈ 2.303
틀린 예측에 자신할수록 손실이 커집니다.
확률은 predict_proba, 최종 범주는 predict로 구분해서 확인합니다.

분류 평가는 정확도·정밀도·재현율·ROC-AUC 등 문제에 맞는 지표를 사용합니다.

BCE: 이진 크로스 엔트로피 · log는 자연로그17
